# Tower War — онлайн-серверы

## Как это устроено

Игрок открывает игру и нажимает **🌐 Онлайн-серверы**. Браузер подключается к центральному WebSocket-серверу. Сервер показывает список свободных комнат.

Создатель делает комнату → она появляется в списке как `1/2`.

Второй игрок выбирает её → становится игроком №2 → сервер сообщает хозяину о подключении.

Только после появления второго игрока хозяин автоматически запускает матч. Сам игровой расчёт остаётся на хозяине матча, а сервер только пересылает игровые команды и снимки состояния между двумя подключёнными игроками. Поэтому IP-адреса игроков знать друг другу не нужно и нахождение в одной Wi‑Fi сети не требуется.

## Запуск своего сервера

Нужен Node.js 18+.

```bash
npm install
npm start
```

После запуска локально:

`http://localhost:8787/`

И в поле **Адрес сервера** можно оставить:

`ws://localhost:8787/ws`

## Интернет для всех игроков

Для настоящего публичного списка комнат сервер `server.js` нужно разместить на машине/хостинге с публичным HTTPS/WSS адресом. Сам HTML уже умеет автоматически использовать тот же адрес:

- страница по HTTPS → `wss://ВАШ-ДОМЕН/ws`
- страница по HTTP → `ws://ВАШ-ДОМЕН/ws`

То есть игрокам достаточно открыть одну публичную страницу игры. Они не вводят IP друг друга.

## Важное ограничение

Комнаты хранятся только в памяти сервера. После перезапуска сервера список комнат очищается. Это специально сделано для простого игрового лобби без базы данных.
